## 主界面

<div className="doc-feature-row">
<div>

主界面集中显示直播间弹幕。顶部菜单用于打开独立窗口，底部显示直播间标题并提供弹幕输入框。

- **窗口置顶**：点击顶部的图钉按钮，切换主窗口是否保持在其他窗口上方。
- **打开功能窗口**：从顶部依次打开礼物、醒目留言、统计、观众列表和设置。
- **发送弹幕**：登录后，在底部输入文字，点击「发送」或按回车发送。
- **查看发言记录**：点击弹幕中的用户名，在用户信息卡中查看本次直播的发言记录。

</div>
<Screenshot src="/mainwindow.png" alt="主界面的菜单、弹幕列表和输入框" width={874} height={1376} caption="主界面总览 · 顶部打开窗口，底部发送弹幕" />
</div>

### 弹幕命令

在主界面底部输入 `/` 可查看命令提示。输入完整命令后，点击「发送」或按回车执行。

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `/title <新标题>` | 修改当前直播间标题 | `/title 今晚一起听歌` |
| `/bye` | 关闭当前直播间的直播 | `/bye` |

<div className="doc-feature-row">
<div>

**使用条件**：需登录当前直播间的房主账号。修改标题时，在 `/title` 后加一个空格，再输入新标题。

`/bye` 会关闭直播，请在准备下播时使用。

</div>

## 礼物与舰长

<div className="doc-feature-row">
<div>

**入口：主界面顶部 → 礼物。** 在独立窗口查看礼物和舰长记录，弹幕较多时也能逐条处理。

- **筛选记录**：填写顶部的最小、最大金额，或开启「仅舰长」。
- **归档记录**：处理完一条记录后点击「归档」；开启「已归档」可查看归档记录，并通过「恢复」移回。
- **删除记录**：单条记录可点击「删除」；「清空」用于清除所有礼物记录，确认前请留意。

</div>

</div>

## 醒目留言

<div className="doc-feature-row">
<div>

**入口：主界面顶部 → 醒目留言。** 单独查看 Super Chat 的金额、发送者和留言内容。

- **查找留言**：在顶部搜索框中输入用户名或留言内容。
- **处理留言**：阅读后可点击「归档」，通过「已归档」开关再次查看。
- **清理记录**：可删除单条留言，或使用「清空」清除记录。

</div>
<Screenshot src="/superchatwindow.png" alt="醒目留言的搜索框和留言记录" width={1502} height={1200} crop={[0, 0, 950, 260]} caption="局部预览 · 搜索入口与留言内容" />
</div>

## 统计与观众

从主界面顶部打开「统计」或「观众列表」。前者查看直播间数据变化，后者查看高能榜和舰长名单。

<div className="doc-feature-pair">
<div>

### 直播间统计

选择预设时间区间，或切换「自定义」指定区间，查看弹幕数量、礼物与 SC 金额，以及对应的趋势图。

<Screenshot src="/statisticswindow.png" alt="统计窗口的时间区间、汇总数据和弹幕趋势" width={1554} height={1312} crop={[0, 0, 1554, 670]} caption="选择时间范围，查看汇总和变化趋势" />
</div>
<div>

### 观众列表

切换「高能榜」与「舰长」标签查看对应名单。若要查看某位观众的发言记录，请回到主界面点击其弹幕中的用户名。

## 界面与语音设置

<div className="doc-feature-row doc-feature-settings">
<div>

**入口：主界面顶部 → 设置。** 在左侧选择对应的设置分类。

- **窗口设置**：选择要显示的消息类型，按需要开启或关闭入场特效。
- **外观设置**：调整主题、透明度、弹幕字体和字号。透明度作用于设置窗口以外的其他窗口。
- **TTS 设置**：分别开启弹幕、礼物和醒目留言播报，选择声源并调整音量；点击「测试 TTS」检查播报效果。

</div>

</div>

## 插件扩展

**入口：设置 → 插件管理。** 从[插件列表](/plugin-list)选择插件，将其 GitHub 插件目录链接粘贴到导入框，点击「导入」。安装后，点击插件旁的「打开」即可在系统浏览器中使用，也可在此删除不再需要的插件。

插件可以接收弹幕、礼物等直播事件。需要自己编写插件时，请继续阅读[插件文档](/plugin-document)。
