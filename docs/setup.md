## 安装

前往 [Releases 页面](https://github.com/powerlive-io/JLiverTool/releases)下载最新版本的安装包，目前提供 Windows、Linux 和 MacOS 三个平台的安装包。

## 基础设置

安装完成后，打开 JLiverTool，点击右上角的 ⚙️ 设置按钮，进入设置页面；为了连接直播间弹幕，你需要扫码登录一个可用的 B 站账号。

账号设置完成后，你可以填写直播间号连接弹幕服务器。

当连接账号所拥有的直播间时，会出现直播标题修改和开关播的选项。

## 软件更新

在“设置 → 关于 → 更新”点击“检查更新”可手动检查新版本。发现更新后，可以选择“稍后”“下载并更新”或“查看更新内容”；查看更新内容会打开 GitHub 发布页。

“下载并更新”会下载当前系统和处理器对应的安装包，校验完成后安装并自动重启。支持 macOS 应用、Windows 安装版和便携版，以及 Linux AppImage/DEB；需要安装权限时，系统会请求授权。macOS 应用和 AppImage/便携版所在目录需可写，开发构建和 Arch 软件包请手动更新。

关于页面提供 `启动时检查更新` 的选项，开启后每次启动软件时会自动检查是否有新版本可用。
