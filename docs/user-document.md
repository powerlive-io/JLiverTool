## 主界面

主界面由顶部菜单栏、弹幕列表和底部状态栏组成。顶部菜单栏可以切换窗口置顶，打开礼物、醒目留言、统计、观众列表和设置窗口。

![主界面的弹幕列表和底部状态栏](/mainwindow.png)

底部状态栏显示当前直播间标题。在输入框中输入文字，点击发送按钮即可发送弹幕。

### 弹幕命令

在输入框中输入以下命令可以执行直播操作：

| 命令 | 用途 |
| --- | --- |
| `/title <new title>` | 修改直播间标题 |
| `/bye` | 关闭直播 |

直播间管理功能需要登录账号与直播间匹配。

![在输入框中使用弹幕命令](/command.png)

## 礼物与舰长

礼物窗口单独显示礼物和舰长记录，方便在弹幕较多时查看。

![礼物窗口](/giftwindow.png)

## 醒目留言

醒目留言窗口用于单独查看 Super Chat 消息。

![醒目留言窗口](/superchatwindow.png)

## 统计与观众

通过顶部菜单栏打开统计窗口和观众列表，查看直播间数据及观众信息。你也可以查询本次直播中指定观众的发言记录。

![统计窗口](/statisticswindow.png)

![观众列表窗口](/audiencewindow.png)

## 界面与语音设置

在设置窗口中调整窗口主题、透明度、字体和字号。语音播报支持弹幕、礼物和醒目留言，可以根据需要开启。

![设置窗口](/settings.png)

## 插件扩展

在设置中的插件管理页面安装、打开和删除插件。插件在系统浏览器中运行，可以通过 `jliverAPI` 接收直播事件。

继续阅读[插件文档](/plugin-document)，或从[插件列表](/plugin-list)选择一个现成插件。
